## Try it yourself

1. Open the public app without signing in. Confirm LIVE QLOO.
2. Set two or three taste circles, a venue,60/90/120 minutes and an achievable minimum. Use public works or creators; choose a specific returned identity if ambiguous.
3. Run the brief. The notebook shows actual workflows. Tested two-circle execution took about a minute; three-circle cases took about two. These are observed cases, not latency promises.
4. Inspect the selected works, rank-backed circle entry points, average-only alternative and host copy. Export the real evidence and Markdown brief.
5. Veto any selected book, artist or film. Review the changed brief and explicitly run again. Confirm the exclusion receipt.
6. Try a strict minimum. A failed constraint stays binding, with diagnostic selections separated from the approved host copy.

Anonymous use is protected by a shared hourly allowance, a judging-period cap and one active lease. A quota failure preserves the brief and reports the approximate recovery wait. Do not reset quota or mislabel the independent local synthetic fixture as live Qloo output. The optional film supplements the required usable app.
